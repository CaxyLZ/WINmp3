# WINmp3 边缘唤醒音乐播放器

一个用 Python 编写的桌面悬浮音乐播放器，由大肥鱼辅助完成，支持本地与网络歌单，带有 Mod 插件系统与系统音频频谱。

## 功能特性

- **边缘唤醒**：鼠标触碰屏幕顶部中间 1/5 处滑出，移开自动缩回。
- **唱片形态**：支持缩小为唱片图标，可拖拽并吸附在屏幕边缘，再次触碰边缘滑出。
- **风格系统**：三套内置风格（深色、浅色、渐变），支持热重载，并自动适配图标黑白颜色。
- **Mod 系统**：支持动态加载外部 Python 脚本，扩展新功能或歌单源。
- **自绘 UI**：纯 QPainter 绘制的悬浮窗与垂直音量条，包含二级弹窗防重叠机制。

## 内置 Mod

`mods/` 文件夹自带以下插件：
- **网易云歌单**：支持扫码登录，解析自建、红心及外部歌单。自动过滤无版权与试听歌曲。
- **B站歌单**：支持扫码登录，输入视频链接提取音频流，通过本地代理转发播放。
- **边缘频谱**：调用系统音频接口（WASAPI），在屏幕边缘显示真实的系统音频频谱。
- **风格生成器**：可视化自定义颜色、渐变，或随机生成新主题。

## 操作说明

- **鼠标触碰顶部中上方**：唤醒或收起播放器。
- **鼠标滚轮**：在播放器界面上滚动调节音量。
- **键盘快捷键**：`←` / `→` 键快退 / 快进 5 秒。
- **系统托盘**：右键点击图标可退出程序。

## 下载与使用

1. 在仓库右侧的 Releases 页面下载最新的压缩包。
2. 解压后双击 `WINmp3.exe` 运行。
3. 首次启动会自动生成所需文件夹（`data/`、`styles/`、`icons/`）。
4. 程序无需安装 Python 环境。
